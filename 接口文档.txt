基础路径: http://localhost:8080

200：成功
400：参数校验失败
401：未登录 / Token无效
403：无权限访问
500：业务错误 / 系统异常

---------------------------------------------------
一、用户模块 /api/user

1.1 用户注册
POST /api/user/register
权限: 无

请求体:
{
    "username": "testuser",
    "password": "123456",
    "realName": "123",
    "email": "test123@example.com",
    "phone": "12321212321",
    "role": "EMPLOYEE",
    "leaderId": 1
}

成功响应:
{"code":200,"msg":"success","data":null}

失败响应:
{"code":500,"msg":"用户名已存在","data":null}


1.2 用户登录
POST /api/user/login
权限: 无

请求体:
{
    "username": "admin",
    "password": "123456"
}

成功响应:
{
    "code": 200,
    "msg": "success",
    "data": {
        "token": "eyJhbGciOiJIUzUxMiJ9...",
        "userId": 1,
        "username": "admin",
        "role": "ADMIN",
        "permissions": ["user:view", "user:manage", ...]
    }
}


1.3 用户登出
POST /api/user/logout
权限: 需登录
请求体: 无
成功响应: {"code":200,"msg":"success","data":null}


1.4 获取当前用户信息
GET /api/user/current
权限: 需登录
请求体: 无

成功响应:
{
    "code": 200,
    "msg": "success",
    "data": {
        "id": 1,
        "username": "admin",
        "realName": "管理员",
        "email": "admin123@example.com",
        "phone": "123123213230",
        "role": "ADMIN",
        "status": 1,
        "leaderId": null
    }
}


1.5 根据用户名查询用户
GET /api/user/info/{username}
权限: user:view
路径参数: username - 用户名

成功响应:
{
    "code": 200,
    "msg": "success",
    "data": {
        "id": 2,
        "username": "testuser",
        "realName": "testuser",
        "role": "EMPLOYEE",
        "status": 1
    }
}


1.6 分页查询用户列表
GET /api/user/list?pageNum=1&pageSize=10
权限: user:view

请求参数:
pageNum - 页码，默认1
pageSize - 每页大小，默认10

成功响应:
{
    "code": 200,
    "msg": "success",
    "data": {
        "total": 38,
        "pages": 4,
        "pageNum": 1,
        "pageSize": 10,
        "list": [...]
    }
}

三、审批模块 /api/approval


3.1 查询待审批列表
GET /api/approval/pending?pageNum=1&pageSize=10
权限: approval:view

请求参数:
pageNum - 页码，默认1
pageSize - 每页大小，默认10

成功响应:
{
    "code": 200,
    "msg": "success",
    "data": {
        "total": 4,
        "pages": 1,
        "pageNum": 1,
        "pageSize": 10,
        "list": [
            {
                "id": 1,
                "applicantName": "testuser",
                "reason": "需要上岗处理项目任务",
                "applyTime": "2026-06-20 10:00:00",
                "status": 0
            }
        ]
    }
}


3.2 审批通过（单个）
POST /api/approval/approve
权限: approval:approve

请求体:
{"applicationId": 1} 

成功响应: {"code":200,"msg":"success","data":null}


3.3 批量审批通过
POST /api/approval/batch-approve
权限: approval:approve

请求体(指定ID):
{"applicationIds": [1, 2, 3]}

请求体(全选):
{"selectAll": true}


3.4 审批拒绝（单个）
POST /api/approval/reject
权限: approval:reject

请求体:
{
    "applicationId": 1,
    "rejectReason": "理由不充分"
}


3.5 批量审批拒绝
POST /api/approval/batch-reject
权限: approval:reject

请求体:
{
    "applicationIds": [1, 2, 3],
    "rejectReason": "名额已满" 
}

或
{
    "selectAll": true,
    "rejectReason": "名额已满"
}


3.6 获取审批统计
GET /api/approval/statistics
权限: approval:view
请求体: 无

成功响应:
{
    "code": 200,
    "msg": "success",
    "data": {
        "pending": 4,
        "approved": 6, 
        "rejected": 4 
    }
}

四、绩效管理模块 /api/performance


4.1 评定绩效
POST /api/performance/evaluate
权限: performance:grade
说明: 使用分布式锁防止并发

请求体:
{
    "userId": 2,
    "grade": "A",
    "comment": "工作表现优秀", 
    "evaluateYear": 2026, 
    "evaluateMonth": 6 
}

等级说明: A-优秀, B-良好, C-合格, D-待提升, E-不合格

成功响应:
{
    "code": 200,
    "msg": "success",
    "data": {
        "id": 1,
        "userId": 2,
        "userName": "testuser",
        "evaluatorId": 1,
        "evaluatorName": "管理员",
        "grade": "A",
        "gradeDesc": "优秀",
        "comment": "工作表现优秀",
        "evaluateYear": 2026,
        "evaluateMonth": 6,
        "status": 0,
        "statusDesc": "待确认",
        "createTime": "2026-06-20 10:00:00",
        "updateTime": null
    }
}


4.2 确认绩效
PUT /api/performance/confirm/{performanceId}
权限: performance:grade
限制: 仅评定人本人可确认
路径参数: performanceId - 绩效ID

成功响应: {"code":200,"msg":"success","data":null}


4.3 获取用户绩效列表
GET /api/performance/user/{userId}
权限: performance:view
路径参数: userId - 用户ID


4.4 获取月度绩效汇总
GET /api/performance/period?year=2026&month=6
权限: performance:view

请求参数:
year - 年份
month - 月份

    "operation": "UserController.login",

    "endTime": "2026-06-30 23:59:59",

    "pageSize": 20 
}

    "code": 200,
    "msg": "success",
    "data": {
        "content": [
            {
                "id": "uuid-xxx",
                "userId": 1,
                "username": "admin",
                "operation": "UserController.login",
                "method": "POST /api/user/login",
                "params": "{\"username\":\"admin\"}",
                "result": "{\"token\":\"...\"}",
                "ip": "127.0.0.1",
                "duration": 156,

5.2 按用户名查询日志
GET /api/log/user/{username}?pageNum=1&pageSize=20
权限: log:view

5.3 按操作类型查询日志
GET /api/log/operation/{operation}?pageNum=1&pageSize=20
权限: log:view

5.4 查询日志详情

5.5 删除日志
